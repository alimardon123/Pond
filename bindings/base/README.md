# bindings/base/ — Shared Cross-Language Files

This directory contains files shared by ALL language SDKs. They define
the contract between the Rust core and any language that calls it via
the C ABI.

## Files

| File | Purpose |
|---|---|
| `pond.h` | **The unified C ABI header.** Declares functions from all three layers: kernel (`pond_kernel_*`), storage (`pond_storage_*`), and codec (`pond_pnd2_*`, `pond_result_*`, `pond_encoder_*`). Also declares `pond_storage_new_s3` for S3-backed storage. |
| `test_c_abi.c` | End-to-end C ABI test for the PND2 codec. 131 checks: round-trips, NULL safety, error paths, 1000-value dataset, 7 Python-generated blobs (all encodings × all vtypes), multi-column encoder. |
| `test_storage_c_abi.c` | C ABI test for the storage layer (write, read, branch, merge, undo). |
| `generate_test_blobs.py` | Generates 7 PND2 blob files using the Python encoder for cross-language compatibility tests. Used by both C and Go tests. |
| `test_blobs/` | Binary PND2 blobs (7 files) covering i64/f64/str/bin × raw/rle/dict/bitpack. Generated by `generate_test_blobs.py`. |

## Usage

### For C/C++ consumers

```c
#include "pond.h"

// Create a storage handle (local FS)
PondStorageHandle* s = pond_storage_new("/var/lib/pond");

// Or S3-compatible storage
PondStorageHandle* s = pond_storage_new_s3(
    "s3://bucket/prefix?region=us-east-1&endpoint=https://s3.amazonaws.com");

// Write + read
const char* hash = pond_storage_write(s, "users", data, data_len, "init");
pond_storage_read(s, "users", &out, &out_len);

// Branch + merge
pond_storage_branch(s, "users", "dev");
pond_storage_checkout(s, "users", "dev");
pond_storage_merge(s, "users", "dev", "main", "merge dev");

// Free handles and strings
pond_storage_string_free((char*)hash);
pond_storage_data_free((uint8_t*)out, out_len);
pond_storage_free(s);
```

### For Go consumers

The Go SDK (`../go/`) wraps this header via cgo. See `../go/README.md`.

### For Java/Node consumers (future)

JNI/N-API wrappers around this header. Not yet implemented.

## Linking

Link against the static libraries (in `target/release/`):

```bash
# Local FS only
cc my_app.c -Ibindings/base \
    target/release/libpond_storage.a \
    target/release/libpond_kernel.a \
    -lpthread -ldl -lm -o my_app

# With S3 support
cc my_app.c -Ibindings/base \
    target/release/libpond_s3.a \
    target/release/libpond_storage.a \
    target/release/libpond_kernel.a \
    -lpthread -ldl -lm -o my_app
```

## Memory Management

The C ABI follows these conventions:
- **Handles** (`PondKernel*`, `PondStorageHandle*`): heap-allocated, must be freed with `pond_*_free()`.
- **Strings returned by functions**: heap-allocated, must be freed with `pond_storage_string_free()` or `pond_kernel_string_free()`.
- **Data returned via out-params**: heap-allocated, must be freed with `pond_storage_data_free()` or `pond_kernel_data_free()`.
- **NULL-safe**: all `free` functions accept NULL (no-op).

## Error Handling

- Functions that return pointers return NULL on error.
- Functions that return `int` return 0 on success, -1 on error.
- Functions that return `const char*` (strings) return NULL on error.
